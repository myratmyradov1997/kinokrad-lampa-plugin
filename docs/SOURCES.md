# Источники: что есть в семействе

Четыре независимых сервиса с одной идеей: тонкий плагин на телевизоре + сервис, который умеет
разговаривать с источником. Каждый ставится отдельно и может работать без остальных.

| Источник | Репозиторий | Порт | Каталог/поиск | Сериалы | Максимум качества | Особенность |
|---|---|---|---|---|---|---|
| **KinoKrad** | этот репозиторий, корень | 5200 | да | да, озвучки + второй плеер | 1080p (4K только AV1) | подпись потока браузером, CDN капризен к IP |
| **Kinogo** | этот репозиторий, `kinogo/` | 5210 | да | да, точная серия/озвучка | 1080p | дерево плейлиста Cinemar, несколько зеркал |
| **Dorama** | [dorama-lampa-plugin](https://github.com/myratmyradov1997/dorama-lampa-plugin) | 5100 | подборки дорам | да | 1080p | кастомная сетка, TMDB-сопоставление |
| **RuTube** | [rutube-lampa-plugin](https://github.com/myratmyradov1997/rutube-lampa-plugin) | 5220 | поиск по видео | нет (фильмы целиком) | 1920×800 / 1280×536 | публичный JSON API, почти без защиты |

## Как они сосуществуют в Lampa

Плагины живут в одном JS-контексте Lampa, поэтому:

- меню **Смотреть → Источники → KinoKrad / Kinogo / Rutube** строит плагин Kinogo;
- у каждого плагина свой префикс компонента, ключ настроек и window-флаг — иначе Lampa
  загрузит только первый;
- блокировка рекламы Lampa ставится один раз и защищена общим флагом `window.lampa_noads_plugin`:
  кто первым загрузился, тот и включает, второй видит флаг и молчит.

Практическое следствие: если переименовать флаг только в одном плагине, реклама начнёт
отключаться дважды, а меню источников может не появиться. Все файлы семейства должны
использовать одинаковые имена.

## Когда какой выбирать

- **KinoKrad** — основной каталог, больше всего озвучек и сериалов; иногда упирается в политику
  CDN (вечерние блокировки по IP/сессии).
- **Kinogo** — второй каталог на случай, если в KinoKrad тайтла нет или он блокируется.
- **Dorama** — дорамы, которых в двух предыдущих может не быть вовсе.
- **RuTube** — когда фильм целиком выложен официально/публично; почти не ломается, но качество
  и наличие зависит от загрузки.

## Чего в этом семействе нет

- нет встроенного торрент-плеера и интеграции с TorrServer;
- нет обхода платного доступа: если источник требует подписку, будет ошибка;
- нет вырезания рекламы, вшитой в сам видеофайл;
- нет хранения медиа: сервисы только проксируют поток.
