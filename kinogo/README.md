# Kinogo для Lampa

Второй источник семейства: `kinogo.film`. Отдельный сервис, отдельный порт (по умолчанию 5210),
общий venv с KinoKrad.

## Запуск

```bash
cd kinogo
PORT=5210 python server.py
curl http://127.0.0.1:5210/api/health
```

Плагин для Lampa: `http://<адрес-сервиса>:5210/plugin.js`.

## Что делает

- поиск и карточки — HTTP-запросы к сайту (`curl_cffi` + `BeautifulSoup`);
- серии и озвучки — из дерева плейлиста Cinemar, развёрнутого в браузере;
- сервер выбирает **точный** `pjs_id` запрошенной серии; при отказе возвращается ошибка, а не
  другая серия;
- медиа идёт через `/media?u=…`: плейлисты переписаны на сервис, сегменты отдаются с `Range`;
- при TLS-ошибке медиазеркала берётся другое зеркало из того же подписанного дерева.

## Настройки

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `5210` | Порт сервиса |
| `KG_BROWSER_PROXY` | пусто | Прокси для браузера и медиазапросов |

## API

`GET /api/health`, `/api/search?q=`, `/api/prepare?title=`, `/api/detail?url=`, `/api/resolve?…`,
`/media?u=…`, `/plugin.js`.

## Особенности

- браузер (Playwright Chromium headless shell) запускается лениво и не блокирует HLS-прокси;
- запуск защищён отдельным lock — параллельные запросы не поднимают второй экземпляр;
- сервис не использует `parsers.py` и `.env` KinoKrad, это самостоятельное приложение.
